    🌐 Breached Passwords Analysis (Have I Been Pwned)

    Zero-knowledge breach verification using the mathematical k-anonymity model. Only 5 hex characters of SHA-1 ever leave your machine.

    🛡️ How K-Anonymity Protects You

    1. Local Hash: SHA-1("password123") = CBFDA C6008F9CAB4083784CBD1874F76618D2A97
    2. Prefix Extraction: Take first 5 hex chars: CBFDA (35 chars kept private)
    3. Anonymous Query: Request range: GET https://api.pwnedpasswords.com/range/CBFDA
    4. Local Match: API returns ~500 hashes sharing that prefix; match is done locally.
    5. Privacy Guarantee: The server never sees the password or full hash!
